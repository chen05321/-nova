# 超体 (Nova) — 自进化 AI 智能体

基于人体 8 大系统隐喻的自进化 AI 框架。每个系统独立运转又通过事件总线耦合，形成完整的生命模拟闭环。

## 一键安装

```bash
git clone https://github.com/chen05321/-nova.git
cd -nova
npm install
nova --setup    # 配置 API Key
nova            # 启动（自动打开看板）
```

## CLI

```bash
nova              # 启动看板
nova --setup      # 配置向导
nova --cli        # 纯终端模式
```

看板内 `/help` 查看全部命令。
