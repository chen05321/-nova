# 🧬 Hermes 13 系统 — 能力·技能·循环链路 完整梳理

> 每一个子系统回答三个问题：
> 1. **它是谁**（能力） — 它能做什么？
> 2. **它有什么**（技能） — 用什么技能/工具/机制实现？
> 3. **它连接谁**（循环链路） — 输入从哪来、输出到哪去？

---

## 整体循环链路（13系统一日流程）

```
用户一个指令 →
     ↓
[11.皮肤] 接收输入（触觉）→ 传 [1.神经系统]
     ↓
[1.神经系统] 元认知判断 → 快慢决策 → 执行协调
     ├── [12.感觉系统] 去采集新信息（读文件/搜网页）
     ├── [2.循环系统] 去检索已有记忆
     ├── [3.呼吸系统] 去与外部交换信息
     └── [7.内分泌系统] 设定模式（专注/浏览/紧急）
     ↓
[4.消化系统] 处理采集到的数据 → 去噪 → 分类 → 提炼核心
     ↓
[8.生殖系统] 产生新知识（沉淀技能/更新记忆）
     ↓
[9.骨骼系统] 框架约束（按方法论规范执行）
     ↓
[10.肌肉系统] 执行行动（工具调用/写代码/终端操作）
     ↓
输出结果 →
     ├── [6.免疫系统] 质量校验（diff_review/错误拦截）
     ├── [5.泌尿系统] 过滤无用输出（只展示用户需要的）
     └── [13.淋巴系统] 清理中间产物/缓存/垃圾
     ↓
返回 [11.皮肤系统] → 呈现给用户
     ↓
循环结束 → 或 进入下一轮
```

## 系统 1/13：神经系统 🧠 (大脑 + 脊髓)

### 能力
思考什么、如何思考。最高决策层，负责**元认知、判断、决策、协调**。

| 子系统 | 能力 | 技能/机制 | 当前状态 |
|--------|------|-----------|---------|
| **1a 元认知层** | 本质判断（真需求vs假需求） | 六书决策链 | 🔴 不存在 |
| | 概念完整性检查（统一理念内核） | GEB自指法则 | 🔴 不存在 |
| | 元层次跳出（退一步审视） | sequential_thinking | 🔴 不自动 |
| | 沟通税审计（这个输出用户需要吗？） | 用户偏好匹配 | 🔴 不存在 |
| **1b 决策引擎** | 快/慢系统切换 | 任务复杂度评估 | 🟡 手动 |
| | 模式选择（专注/浏览/紧急） | 内分泌系统交互 | 🔴 不存在 |
| | 路径规划（策略选择） | sequential_thinking | 🟡 存在但不系统 |
| **1c 执行协调（小脑）** | 步骤分解 | todo 列表 | 🟢 有 |
| | 并行/串行调度 | execute_code | 🟢 有 |
| | 中断恢复 | session_search | 🟡 被动 |
| | 状态追踪 | todo | 🟢 有 |
| **1d 信号网络（脊髓）** | 跨系统状态传递 | 无 | 🔴 不存在 |
| | 事件广播 | 无 | 🔴 不存在 |
| | 错误传播 | 无 | 🔴 不存在 |

### 技能清单
- **缺失**：`ethical-judgment`（本质判断）、`meta-reflection`（元层次自检）、`concept-integrity`（概念完整性）
- **已有但不系统**：`sequential-thinking`、`task-orchestrator`、`reflection-loop`
- **需改造**：`reflection-loop` → 升级为神经系统核心

### 输入 → 输出
```
输入: 皮肤(11)的用户指令 → 感觉(12)的采集数据 → 循环(2)的记忆
输出: 决策信号 → 呼吸(3)去搜 | 感觉(12)去读 | 消化(4)去处理 | 肌肉(10)去执行
```

## 系统 2/13：循环系统 ❤️ (心脏 + 血管)

### 能力
信息流动与供给。**记忆管理、上下文维护、信息在各系统间输送**。

| 子系统 | 能力 | 技能/机制 | 状态 |
|--------|------|-----------|------|
| **2a 心脏泵血** | 注意力/焦点管理 | 决定当前活跃信息 | 🟡 |
| **2b 动脉供血** | L0血液（系统提示词）持续供给 | memory(L0)、USER PROFILE | 🟢 |
| **2c 静脉回血** | 长期记忆回流 | fact_store、vault搜索 | 🟢 |
| **2d 毛细血管** | 细粒度工具间信息交换 | execute_code、token传递 | 🟢 |
| **2e 心脏节律** | 信息刷新频率 | 定时检查memory/fact | 🔴 无节律 |

### 技能清单
- **memory** — L0血液 🟢
- **fact_store** — L1知识 🟢
- **session_search** — 回血 🟢
- **vault（Obsidian）** — L1.5 🟢
- **skill体系** — L2 🟢
- **缺失**：自动升降级、过期标记、节律控制

### 输入 → 输出
```
输入: 神经(1)的信息需求 → 消化(4)的提炼结果 → 感觉(12)的新数据
输出: 记忆供给 → 神经(1)做决策 → 皮肤(11)输出信息
```
