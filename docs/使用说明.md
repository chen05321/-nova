# 超体 (Nova) 使用说明

## 环境要求
- macOS / Windows / Linux 均可
- Node.js 18 或更高版本
- DeepSeek API Key（免费注册: https://platform.deepseek.com）

---

## 快速开始

### 第一步：安装
```bash
cd nova
npm install
bash install.sh
```

### 第二步：配置 API Key
```bash
# 方式一：运行配置向导（推荐）
nova --setup

# 方式二：手动设置环境变量
export DEEPSEEK_API_KEY=sk-你的key

# 方式三：写入配置文件
echo 'DEEPSEEK_API_KEY=sk-你的key' > ~/.nova/.env
```

### 第三步：启动
```bash
nova
```

## 使用方式

### 普通对话
直接输入文字，超体会调用 LLM 回复你。

```
You: 帮我介绍一下你自己
Hermes: 我是超体，一个基于人体8大系统的自进化AI助手...
```

### 自主任务
输入 `/task <目标>`，超体会自动拆解任务、调用工具、给出结果。

```
You: /task 帮我分析当前目录有哪些文件
```

### 查看系统状态
```
You: /status
```
显示八大系统的运行状态和负载。

### 查看激素水平
```
You: /hormones
```
显示肾上腺素、皮质醇、多巴胺等激素水平。

## 加装 MCP 插件

超体支持 MCP（Model Context Protocol）标准插件。

创建 `nova.mcp.json`:
```json
{
  "filesystem": {
    "command": "npx",
    "args": ["-y", "@modelcontextprotocol/server-filesystem", "."]
  }
}
```

可用的 MCP 服务器列表：https://github.com/modelcontextprotocol/servers

## 常见问题

**Q: 没有 API Key 可以用吗？**
A: 不行，首次使用需要运行 `nova --setup` 配置 Key。

**Q: DeepSeek API Key 怎么获取？**
A: 去 https://platform.deepseek.com 注册账号，在 API Keys 页面创建即可，有免费额度。

**Q: 超体数据存在哪里？**
A: 对话记忆存于 `~/.nova-memory/memory.json`，配置存于 `~/.nova/.env`。

**Q: 怎么换用 OpenAI 或 Claude？**
A: 设置环境变量 `OPENAI_API_KEY` 或 `ANTHROPIC_API_KEY` 即可自动切换。
